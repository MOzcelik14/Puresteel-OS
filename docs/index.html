Puresteel

A Debian 13 based Linux distribution built around KDE Plasma 6, with Intel, AMD and NVIDIA graphics support, preinstalled gaming, creator and developer tooling, a graphical installer and its own system management layer.

Rolling installer: the latest successful main build. The temporary r2.dev mirror is rate-limited; check SHA256 before writing USB media.

System

Puresteel keeps the Debian base familiar while shipping focused desktop and system-management defaults.

KDE Plasma 6

KDE Plasma 6 with SDDM, Breeze Light, Puresteel branding and Wayland/X11 sessions.

Graphics

Intel and AMD through Linux/Mesa, plus Debian's NVIDIA driver stack and hybrid-GPU integration.

Gaming & creation

Vulkan-ready graphics; preinstalled Steam, Wine, Heroic, Kdenlive and Audacity; more apps through Puresteel Center.

Puresteel Center

A Qt-based control center for updates, applications, drivers, sources, backups and system reports.

Language

Puresteel Language Settings provides system-wide Turkish and English switching.

Live & install

Hybrid live media with Calamares for graphical installation on UEFI systems.
