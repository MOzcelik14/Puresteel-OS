Puresteel

A Debian 13 based Linux distribution built around KDE Plasma, with integrated Intel, AMD and NVIDIA graphics support, gaming and creator tooling, a graphical installer and its own system management layer.

Build the ISOInstallationSource

System

Puresteel keeps the base familiar and the distribution-specific pieces focused.

KDE Plasma

Plasma desktop, SDDM, Wayland and Puresteel branding with a minimal default layout.

Graphics

Intel and AMD through the Linux/Mesa stack, plus Debian's NVIDIA driver stack and hybrid-GPU integration.

Gaming & creation

Steam, Wine, Winetricks, Vulkan, Heroic, ProtonUp-Qt, Kdenlive, Audacity and other desktop tools.

Puresteel Center

A Qt-based control center for updates, applications, drivers, sources, backups and system reports.

Updates

Debian APT, Flatpak and a signed Puresteel package repository for Puresteel-owned components.

Live & install

Hybrid live media with Calamares for graphical installation on UEFI systems.

Build the ISO

On a Debian, Ubuntu or Linux Mint style host, the bootstrap script installs the required build tools, fetches the release source and produces the ISO locally.

One command
curl -fsSL https://raw.githubusercontent.com/MOzcelik14/Puresteel-OS/main/bootstrap.sh | bash
